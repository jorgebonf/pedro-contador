# Pedro · O Contador — pacote para publicar (PWA) · v2.1.0

## Atualizar no GitHub (repositório pedro-contador)
1. Extraia o ZIP.
2. No repositório: Add file → Upload files → arraste TODO o conteúdo da pasta (inclusive a pasta icons).
3. Commit changes. Em alguns minutos o site é atualizado.
4. No celular, feche e abra o Pedro (com internet) para receber a nova versão. Seus dados não são apagados.

## Novidades desta versão
- A tela não aproxima (zoom) ao abrir o Pedro nem ao abrir o formulário de despesa.
- Campos com fonte de 16px no celular (o iPhone dá zoom automático em campos menores).
- No celular, o formulário abre como painel inferior e não puxa o teclado sozinho.
- Fundo travado enquanto o formulário está aberto.

## Futuras atualizações
Substitua o index.html e aumente VERSION no sw.js (ex.: v2.1.0 → v2.1.1).
